💚 Nova Cidade — Juntos Somos Mais Fortes
Um projeto web desenvolvido para apresentar o trabalho social da ONG Nova Cidade – Juntos Somos Mais Fortes, divulgar suas iniciativas e facilitar a participação de pessoas interessadas em contribuir com a comunidade.

Este site foi desenvolvido para reunir informações sobre a iniciativa em um só lugar, apresentar suas ações e mostrar como a comunidade pode participar.

🎯 Objetivos do site
- Apresentar a história e a missão do projeto social.
- Divulgar as ações e iniciativas desenvolvidas pela ONG.
- Apresentar o portfólio institucional.
- Incentivar a participação de novos voluntários e parceiros.
- Informar como contribuir com doações.
- Facilitar o contato com o projeto.
- Oferecer uma experiência de navegação acessível e responsiva em diferentes dispositivos.

✨ Funcionalidades
- Página inicial: apresentação do projeto, destaques das ações e chamadas para participação.
- Quem somos: história e apresentação institucional.
- Projetos e ações: divulgação das iniciativas sociais.
- Cursos e atividades: apresentação das atividades esportivas, educativas e culturais divulgadas pelo projeto.
- Portfólio: visualização do documento institucional.
- Voluntariado: informações para pessoas interessadas em colaborar.
- Doações: apresentação das formas de contribuição informadas pelo projeto.
- Contato: acesso aos canais de comunicação.
- Navegação entre páginas: rotas gerenciadas com React Router.
- Layout responsivo: adaptação para celulares, tablets e computadores.

A disponibilidade de cada ação, curso ou serviço deve ser confirmada com a equipe responsável pelo projeto.

🧩 Organização do front-end
O projeto utiliza componentes React e páginas separadas, com estilos organizados em CSS Modules. A interface foi planejada com abordagem mobile-first, usando Flexbox para organizar os elementos e pontos de quebra para adaptar o layout a diferentes larguras de tela.

O site é uma aplicação front-end. Na versão atual, não depende de banco de dados próprio.

📱 Responsividade
O layout começa pela experiência em dispositivos móveis e é adaptado para telas maiores com media queries.

Pontos de quebra utilizados no projeto:
- 600 px: ajustes para telas médias.
- 850 px: ajustes para tablets maiores e computadores.
- 1200 px: refinamentos para telas amplas.
